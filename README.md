## 🌐 1. 3D Interactive Developer Portfolio

### Overview
This project represents a massive upgrade from a standard static portfolio to a fully dynamic, physics-based 3D web experience. Designed to push the boundaries of modern web technologies, the portfolio features a responsive 3D character integration, fluid scroll animations, and interactive elements built to perform beautifully across both desktop and highly-constrained mobile viewports.

### 🚀 Live Demo
Check out the live portfolio: **[Zishan Ali Portfolio](https://flourishing-kitsune-e3810c.netlify.app/)**

### 🛠️ Tech Stack
- **Framework:** React & Vite
- **3D Rendering:** Three.js / WebGL
- **Animation:** GSAP (ScrollTrigger & custom physics interactions)
- **Styling:** Custom CSS Grids, Flexbox, & Glassmorphism UI
- **Mobile Optimization:** Responsive Canvas resizing, dynamic pixel-ratio capping, and conditional 3D physics rendering to ensure a smooth 60fps experience on mobile devices.

## 🧩 2. LeetCode Insights Chrome Extension

### Overview
A lightweight, vanilla JavaScript Chrome extension that seamlessly integrates with LeetCode. It injects real company tags, logos, and interview frequency data directly into the LeetCode problemset, helping developers prioritize their interview preparation.

### ✨ Key Features
- **Inline Company Badges:** Displays company names, brand logos, and frequency counts cleanly next to problem titles.
- **Dedicated Company Filter:** A custom floating modal that allows you to instantly search and view all problems asked by a specific company without fighting LeetCode's native pagination.
- **Lightweight & Fast:** Built with pure JavaScript, HTML, and CSS. All data is fetched locally via a massive dataset mapping over 3,300+ problems for instant lookups.
- **Non-intrusive UI:** Respects LeetCode's native layout, working smoothly across both light and dark modes.
