![Portfolio Preview](./public/images/og-image.jpg) <!-- Update this path if needed -->

## Overview
Welcome to the source code of my interactive developer portfolio. This project represents a massive upgrade from a standard static portfolio to a fully dynamic, physics-based 3D web experience. 

Designed to push the boundaries of modern web technologies, the portfolio features a responsive 3D character integration, fluid scroll animations, and interactive elements built to perform beautifully across both desktop and highly-constrained mobile viewports.

## Tech Stack
- **Framework:** React & Vite
- **3D Rendering:** Three.js / WebGL
- **Animation:** GSAP (ScrollTrigger & custom physics interactions)
- **Styling:** Custom CSS Grids, Flexbox, & Glassmorphism UI
- **Mobile Optimization:** Responsive Canvas resizing, dynamic pixel-ratio capping, and conditional 3D physics rendering to ensure a smooth 60fps experience on mobile devices.
